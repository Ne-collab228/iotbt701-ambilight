# Полоса IOTBT701 BLE — управление с Windows и Ambilight

> 🌐 Язык документации: [English](README.md) | **Русский** | [Español](README.es.md) | [中文](README.zh-CN.md) | [Português](README.pt-BR.md)

Разработанный в обратную сторону контроль BLE LED-полосы семейства
**Zengge / IOTBT** («IOTBT701», MAC `08:65:F0:DE:37:01`) с ПК на Windows 10/11 —
**без фирменного приложения, без сопряжения, без облака**. Включает готовую
программу **Ambilight**: средний цвет экрана → полоса, с окном настроек.

Всё здесь **проверено на физическом устройстве** 30–31.10.2026. Знания
протокола опираются на open-source проект
[8none1/lednetwf_ble](https://github.com/8none1/lednetwf_ble) (интеграция
Home Assistant) плюс наши собственные измерения на этом экземпляре.

## Что работает (проверенная матрица)

| Возможность | Статус | Транспорт |
|---|---|---|
| BLE-поиск (полоса вещает `IOTBT701`) | ✅ проверено | BLE adv, RSSI −56..−86 дБм |
| GATT-подключение + удержание (`GattSession.MaintainConnection`) | ✅ проверено | сервис `FFFF` |
| Запись команды (write-without-response) | ✅ проверено | характеристика `FF01` |
| ВКЛ / ВЫКЛ | ✅ проверено | payload `3B 23 / 3B 24` |
| Белый (насыщенность 0) | ✅ проверено | v3-цвет + legacy `3B A1` |
| Цвет (hue 0..359, прогон 12 оттенков + длительная эксплуатация) | ✅ проверено | **`E0 01 00 A1` (colour_data_v3)** |
| Конверсия RGB → HSV | ✅ проверено | хелперы C# в этом репо |
| Ambilight (средний цвет экрана → полоса, GUI, настройки) | ✅ проверено | `AmbilightOT.exe` |
| Интеграция в автозагрузку + логирование сбоев (v1.5) | ✅ проверено | галочка автозагрузки + `ambilight_log.txt` + автоокно «LINK LOST» |
| Notify/обратное чтение состояния (FF02) | ✅ проверено (запрос `81 8A 8B 40` в семействе `0x0A`; статус-кадр `EA 81 … F0 <hue> <sat> <bri>`; регистры отражают только состояние телефон-приложения) | характеристика `FF02` |
| Шкала яркости | ✅ проверено: байт = **процент 0..100**; значения >100 ломают цвет | байт яркости v3 |

**Ключевая неочевидная находка:** устройство **игнорирует все классические
цветовые команды** (`31/41/42/46 R G B ...`, а также `3B A1 <hue> <sat> <bri>`
везде, где hue ≠ 0). Цвет двигает только **v3-обёртка `E0 01 00 A1 ...`**
(«the E0 01 envelope is load-bearing» — тот же вывод, что в PR #101 из
lednetwf_ble).

**Ключевая находка по этому экземпляру:** при полной насыщенности пара
байтов hue — это `<hue/2> <sat>` только для **чётных** градусов hue.
Нечётная кодировка (`lo = sat + 128`) прошивкой этого устройства
**понимается неправильно** (azure 193° дал неверный/инертный результат).
Применённый фикс: квантование hue к ближайшему **чётному** градусу
(ошибка ≤ 1°, глазом невидима).

## Инструменты

| Программа | Назначение |
|---|---|
| `AmbilightOT.exe` | Ambilight: снимает основной монитор ~1.4 раза/с, считает доминирующий цвет, управляет полосой. WinForms GUI с живым превью цвета и настройками. Дружелюбно к ярлыку (закрыл окно — полоса держит цвет, пульт снова работает). **v1.5:** галочка «запускать с Windows» (ярлык в shell:startup), файл `ambilight_log.txt` с точностью до мс и ротацией 512 КБ, кнопка «лог подключений», автоматическое окно с полным логом **LINK LOST** при самовольном отключении полосы |
| `ledctl.exe` | Консольный тестер: `on`, `off`, `white`, `rgb R G B`, `hsv H S B`, прогон 12 цветов (яркость зажата на шкале 0–100 %) |
| `lednotify.exe` | Обратная связь FF02: `query` запрашивает статус-кадр, `ladder`/`l0a` — эксперименты яркости с чтением ответа, `listen` — слежение за событиями пульта/приложения |
| `blescan.exe` | Сканер BLE-объявлений, 25 с |

## Замечания по безопасности / этикету

- Частота записи: **проверено до ~17 команд/с длительно** (сок-тест 3.5 мин: 3600/3600 доставлено,
  линк стабилен, без backlog); пачки даже 456/с встали в очередь без потерь. Старое «2.5/с» было перестраховкой.
- Фирменное телефонное приложение (Surplife/Zengge) должно быть закрыто, пока
  PC-инструмент держит линк; полоса принимает **одного** GATT-клиента.
- Закрытие управляющей программы оставляет последний цвет на полосе и
  возвращает пульт; сверх штатного поведения устройства ничего не меняется.
