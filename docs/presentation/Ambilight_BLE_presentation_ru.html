Как запись скользит к цели
4

Демо считает шаги по формуле из отчёта: доля остатка 2/(N+1). Порог снапа в демо 2%, в приложении снап точный. Цвета квадратов только иллюстрация.

05 · ВЕРНУТЬ
Обрыв → зановополный цикл подключения каждые ~6 с, бесконечно
Почему без pairing: Windows PairAsync для этой ленты всегда возвращает Failed. Лента сопряжения не требует: GATT-характеристики открыты, а сопряжение только ломает доступ.

Наведите на байт

Заголовок транспорта, команда цвета v3 и контрольная сумма. Двигайте ползунки: HH, SS, BB и CS пересчитываются по формуле из отчёта.

Демо считает кадр по формуле из отчёта. Hue всегда чётный: нечётные градусы прошивка искажает, ошибка в 1° не видна.

00 · Обрывы линка · 08.11

101 обрыв: что показал лог

0

обрыв линка с 02.11 по ambilight_log.txt. Лента на секунду пропадает и сама возвращается.

Обрывает не программа. Записи шли нормально, затем Windows сама присылает ConnectionStatus → Disconnected.
Автореконнект работает. Линк возвращается за 1–6 с.
Сколько жил линк, логарифмическая шкала

Исключено

  • Wi-Fi 5 ГГц (канал 149) помехой не считается
  • Наушники были выключены, A2DP не причина

Под подозрением

  • Подвисший BT-стек Windows после сна
  • Питание или перезагрузка контроллера ленты
  • Радиопомехи
  • Экономия питания адаптера: Realtek 8852BE, Wi-Fi и BT на одном чипе, «разрешить отключение для экономии энергии» включено
00 · Решение v1.9

Обрывы не чиним, а делаем незаметными

Как отличить причину
1
Surplife на телефоне во время обрывовСтабильно: виноват ПК или адаптер. Тоже рвётся: виновата лента или её питание.
2
Перезапуск BT-адаптера или перезагрузкаЛинк снова живёт десятки минут: виноват стек после сна.
3
Снять галочку экономии питанияУ Realtek Bluetooth Adapter: «разрешить отключение для экономии энергии».
Релиз v1.9, коммит 889b533. Резервная копия прежнего exe: AmbilightOT_v1.8_backup.exe. В эфире «NOT SEEN» при активном линке это норма: BLE в соединении не рекламируется.
13 · Инструменты и репозиторий

Один GUI и четыре консольных помощника

AmbilightOT.exe

Главный продукт. Интервал 50 мс…3 с, усиления sat/bri, мин. яркость, порог белого, тёплая поправка, плавность по времени, тёмный интерфейс с кнопкой ПУСК/СТОП, 5 языков, автосохранение, автозагрузка, лог, тихий реконнект.

ledctl.exe

Консоль: white / on / off / rgb / hsv / sweep2.

lednotify.exe

Обратная связь и эксперименты: query / listen / ladder / rate / soak / send.

blescan.exe

BLE-скан 25 с: жива ли лента в эфире, когда никто не держит линк.

build_*.ps1

Сборка через csc.exe, GAC-фасады и WinMD, вообще без Visual Studio.
